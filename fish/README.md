# 潮渊 · 鲸蓝之誓

以 DeepSeek 蓝发鲸鱼女仆网络形象为灵感的原创同人 3D 动作游戏。无官方关联。使用程序化模型、场景和合成音效，全部资源在本地，无需构建或联网。

直接在现代 Chrome / Edge / Firefox 中打开 `index.html`，或用 IDE 的静态服务器预览 `fish/`。需要支持 WebGL、开启硬件加速。手机支持触屏，建议横屏。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动 / 疾跑 | WASD / Shift |
| 轻击 / 重击 | J 或鼠标左键 / K 或鼠标右键 |
| 翻滚 | 空格，消耗 26 体力，中段拥有无敌帧 |
| 弹反 | E，动作前 0.29 秒内迎接横斩，成功后敌人失衡 |
| 潮露 | Q，3 次，每次恢复 55 生命，可被打断 |
| 目标锁定 | Tab，默认开启 |
| 视角 / 缩放 | 左右方向键或鼠标中键拖动 / 上下方向键或滚轮 |
| 暂停 / 声音 / 全屏 | Esc / M / F |
| 重试 | 倒下或胜利后按 R |

## 战斗

主角轻击范围为 2.73、重击范围为 3.15。普通轻击伤害 39，第三段轻击 52，重击 83，弹反 126；按先前伤害的 70% 四舍五入，失衡追击仍享受伤害加成。刀光剑气与判定范围同步。

守卫在攻击前会先摆出明显的蓄力姿势并停留：横斩侧身收槊、砸地双手举槊、冲锋俯身架槊。基础前摇分别为横斩 1.5 秒、砸地 1.9 秒、冲锋 1.7 秒、连斩首击 1.35 秒、次击 1.05 秒；二阶段所有动作统一为一阶段的二倍速，移动速度翻倍，前摇、出招、收招、连斩间隔及失衡时间减半，动画与判定同步。蓄力时武器发光，画面显示实际剩余时间和进度条；可弹反招式仍在出手前 0.18 秒转为蓝光，并发出提示音。

守卫有横斩、二连斩、冲锋和定点砸地。砸地与二阶段爆发的圆形范围固定为半径 2.7，与地面预警一致，仅在爆发瞬间判定一次伤害，不会扩散或留下持续伤害。可提前走出圆圈，也可用翻滚无敌帧避开爆发。横斩前的蓝色提示代表弹反时机。体力恢复需要停止攻击与翻滚，疾跑也会消耗体力。保持至少一次翻滚的余量。

重击和三连击最后一击可累积失衡，弹反成功可以直接打断横斩。守卫生命降至一半时进入怒潮阶段，招式更快。砸地和冲锋无法弹反，需要走位或翻滚。倒下时恢复全部生命、体力、潮露并重置守卫。死亡次数和最快通关时间保存在浏览器本地（可用时）。

命中会触发顿刀、方向性震屏、护甲闪光和接触火花，重击、连击终结与弹反的反馈更强。挥刀轨迹与伤害时机同步，空挥只有破风声。镜头冲击与受击后仰只影响表现，不改变碰撞和攻击判定。

## 文件

- `index.html`：界面和操作说明。

- `vendor/three.min.js`：Three.js r160，MIT 许可证见 `vendor/THREE-LICENSE.txt`。
