# NEURAL CLASH · 深海与余烬

在浏览器中运行的 2D 同人格斗游戏。DeepSeek 蓝发鲸鱼娘对阵 Claude 橙发少女，角色、背景和特效全部使用 Canvas 2D 程序绘制。

## 运行

直接用 Chrome 或 Edge 打开 `index.html`，点击「开始对决」。不需要安装、构建或联网。也可以通过任意静态文件服务器打开此目录。

提供三种模式：单人 CPU 对战（轻松、标准、挑战）、本地双人对战、自由训练。正式对战每回合 99 秒，先赢两回合获胜。训练模式拥有无限 Tension 和爆发，双方停止受击一段时间后自动恢复生命，按 R 重置。

## 键盘操作

| 动作 | P1 · 鲸鱼娘 | P2 · 橙发少女 |
| --- | --- | --- |
| 移动、下蹲 | A / D、S | ← / →、↓ |
| 跳跃、二段跳 | W | ↑ |
| 轻拳 / 踢击 / 斩击 / 重击 | J / K / L / U | 小键盘 1 / 2 / 3 / 4 |
| 飞行道具 | O | 小键盘 5 |
| 升龙 | I | 小键盘 6 |
| 超必杀（50% Tension） | H | 小键盘 0 |
| 冲刺、空中冲刺 | 空格 | 小键盘 . |
| 罗曼取消（50% Tension） | Q | 小键盘 7 |
| 蓝色爆发（爆发槽满） | E | 小键盘 8 |
| 原地防御 | Shift | 小键盘 9 |

按住远离对手的方向也能防御。蹲踢需要蹲防，空中攻击需要站防。Esc 暂停或继续；Enter 开始或继续；Shift + /（?）打开指南。手机提供触屏方向和招式按钮，镜头自动跟随双方。

## 连段与资源

- 命中或被防御后，可由轻拳 → 踢击 → 斩击 → 重击递进取消，再接波动、升龙或超必杀。可以跳过中间等级，但不能倒序取消。试试 `J → K → L → O`。
- 攻击、受击和向前移动积累 Tension。超必杀和罗曼取消各消耗 50%；罗曼取消可立即取消动作并暂缓对手，受击时不能使用。
- 蓝色爆发可以在受击中脱身，消耗完整爆发槽，短暂无敌并击退附近对手；爆发槽随时间及受击恢复。
- 二段跳与一次空中冲刺在落地后恢复。升龙启动与超必杀有短暂无敌。连段伤害逐段衰减；打断对手出招前摇会触发 Counter。
- 波动之间可以互相抵消，超必杀可以压过普通波动。飞行道具有发射间隔。

## 手柄

支持浏览器标准映射手柄；第一个连接的手柄控制 P1，第二个控制 P2（双人模式）。

方向键 / 左摇杆移动，A 跳跃，X / Y / B / RB 对应轻、脚、斩、重。LB 冲刺、LT 波动、RT 升龙；下 + RT 超必杀，下 + LB 取消，下 + RB 爆发；Start 开始或暂停。

## 实现

- `index.html`：界面、血量和资源显示、模式选择、内置操作手册。
- `style.css`：响应式布局、深海蓝与余烬橙主题，使用本机字体，无外部资源请求。
- `game.js`：固定 60 Hz 战斗模拟、输入缓存、碰撞、AI、手柄及触屏输入、分层角色骨骼动画、粒子、镜头和 Web Audio 合成音效。

声音默认关闭，点击顶部「声音 OFF」开启。页面失去焦点自动暂停。「操作指南」会暂停游戏，关闭后恢复。镜头震动和画面闪光尊重系统的减少动态效果设置。

这是借鉴动漫格斗游戏节奏的原创简化动作系统，必杀采用单键输入。角色为社区拟人形象的原创同人演绎，未使用《罪恶装备》或相关品牌的官方美术、角色、音频素材。
